# Demo Assets

Place recorded walkthrough media and Streamlit screenshots in this directory.

Recommended files:

| File | Purpose |
|---|---|
| `demo.gif` | 30-60 second walkthrough covering Agent task input, tool trace, evidence chain, and final report export. |
| `agent_workbench.png` | Agent workbench showing natural-language task, analysis plan, tool calls, observations, and final conclusion. |
| `evidence_chain.png` | Evidence chain page showing step-by-step trace from source layer to breakpoint. |
| `severity_cases.png` | Exception severity and matched historical cases. |
| `validated_export.png` | Validated revenue, allocated expense, and validation summary export results. |

Do not commit raw audit reports, local `.env` files, API keys, or private data in this directory.
