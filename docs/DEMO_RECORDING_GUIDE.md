# Demo Recording Guide

## Recommended 30-60 Second GIF Flow

1. Open the Streamlit app.
2. Select accounting period `2025-03`.
3. Open Agent Workbench.
4. Submit sample task:
   “请分析 2025-03 经纪佣金收入差异最大的异常，并定位根因。”
5. Show generated plan.
6. Show tool-call trace.
7. Open the evidence-chain section.
8. Show final root-cause conclusion.
9. Export validated data.
