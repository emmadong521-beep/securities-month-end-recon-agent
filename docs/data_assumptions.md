# 数据假设

本项目仅用于个人研究型 PoC，不代表真实长江证券内部数据，不构成投资建议。

## 来自审计报告公开披露的数据

使用 2025 年审计报告中的公开汇总口径作为规模校准，包括：

- 营业总收入
- 手续费及佣金净收入
- 代理买卖证券业务收入
- 业务及管理费
- 核心资产负债表科目

## 合成数据

以下明细均为合成数据，金额单位为人民币元：

- 客户
- 交易流水
- 佣金计算
- 收入子账
- 总账凭证
- 营业部
- 费用池
- 分摊规则
- 分摊因子
- 接口日志

## 业务线拆分假设

经纪佣金以代理买卖证券业务收入为核心校准口径。财富管理代销收入
单独进入 `6022` 科目，但在 `2025-09` 和 `2025-10` 故意埋入误映射
到 `6021` 的异常。

## 费用分摊假设

- IT 系统成本按交易笔数分摊。
- 行情资讯成本按活跃客户数分摊。
- 总部管理成本按人头分摊。
- 研究支持成本按收入分摊。
- 营业部运营成本按面积或网点规模分摊。

## 异常案例设计

`2025-03` 至 `2025-10` 分别埋入以下演示案例：

- 未入子账
- 少入总账
- 重复凭证
- 科目映射错误
- 分摊比例不满
- 规则版本错误
- 分摊因子缺失

## 合规说明

不包含任何未公开重大信息、客户隐私数据或商业秘密。审计报告只用于
公开披露汇总口径校准，明细全部合成。
