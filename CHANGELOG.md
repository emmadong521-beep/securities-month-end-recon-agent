# Changelog

## v0.1.0

Initial securities finance AI PoC release.

### Added

- Synthetic securities month-end reconciliation data.
- Brokerage commission reconciliation.
- Cost allocation validation.
- Exception severity grading.
- Evidence-chain tracing.
- Similar root-cause case matching.
- Deterministic Agent Mode + Optional LLM Enhancement.
- Validated data export.
- Data quality report.
- GitHub Actions CI and coverage.

### Notes

- Detailed transaction, voucher, branch, customer, and operating data is
  synthetic.
- LLM is optional and does not perform financial calculation.
